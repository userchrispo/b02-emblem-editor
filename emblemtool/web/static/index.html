Mode

The game already loaded an emblem this session. Save it in-game first, then restart Black Ops II (or switch to Zombies and back to Multiplayer) before Show-ing another. Backing out of the editor is not enough.

Save in the in-game editor or it will vanish. Show mode only previews the emblem while the PS5 is using this proxy — including on your player card. Open your own emblem editor and save, the same way you save something you painted. Then switch to Off and check. If you never saved in-game, disconnecting takes it off your account.

The editor only checks once per session. After you open your emblem editor the first time, the game caches what it loaded and won't check again, even if you select a different emblem here. To copy a second one: save the first in-game, restart the game or switch to Zombies and back to Multiplayer, select the next card, Show, then save it to a different slot.

Locked shapes won't work. If a captured emblem uses a shape, rank, or weapon icon your own account hasn't unlocked, the game may fail to load or save it. That's Black Ops II enforcing it, not something this tool can get around.
